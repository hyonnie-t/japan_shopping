# 일본 쇼핑 도감 ♡

일본 여행에서 폰으로 보는 개인용 쇼핑 목록이에요. 사진으로 찾고, 일본어 이름을 직원에게 보여 주고, 산 것을 체크해요. 인터넷이 끊겨도 동작해요.

## 쓰는 법
1. 폰 사파리(또는 크롬)로 앱 주소를 열고 **홈 화면에 추가**해요. 그래야 오프라인에서도 열리고 저장 공간이 지워지지 않아요.
2. 상품을 누르면 사진·일본어 이름·가격·판매처가 나와요. «직원에게 보여 주기»를 누르면 일본어가 크게 떠요.
3. 매장에 들어가면 **매장 모드**에서 그 매장을 고르고, 산 것은 «샀어요»를 눌러요. 실수하면 «되돌리기».
4. 환율은 위쪽 «1엔 = □원»에서 바꿔요(기본 9.20원 = 최근 1년 평균, 2026-10-27).
5. 설정 > 백업에서 JSON으로 내보내 두면 폰을 바꿔도 옮길 수 있어요(사진 포함).

## 구글 시트 동기화(선택)
`apps-script/Code.gs`를 구글 시트의 앱스 스크립트에 붙여 넣고 웹 앱으로 배포한 뒤, 앱 설정에 웹 앱 주소와 비밀번호를 넣어요. 처음 «연결 확인»을 누를 때 넣은 비밀번호가 정해져요. 시트에서 일본어 이름·가격을 직접 고쳐도 앱이 받아 가요.
