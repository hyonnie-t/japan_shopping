# 위시 도감 ♡

사고 싶은 물건을 사진과 함께 담아 두는 개인용 도감이에요. 목록을 여러 개 둘 수 있어요. 처음엔 «일본 여행»(엔화)과 «위시리스트»(원화) 두 개가 있어요. 인터넷이 끊겨도 동작해요. (2026-10-27 «일본 쇼핑 도감»으로 시작, 2026-10-29 위시 도감으로 넓힘)

## 쓰는 법
1. 폰 사파리(또는 크롬)로 앱 주소를 열고 **홈 화면에 추가**해요. 그래야 오프라인에서도 열리고 저장 공간이 지워지지 않아요.
2. 위쪽 초록 단추로 목록을 골라요. ＋로 담을 때 «담을 목록»을 바꿀 수 있고, 나중에 수정에서 다른 목록으로 옮길 수도 있어요.
3. **원화 목록**(위시리스트 등): 가격·어디서·구매 링크를 적어요. 상세의 «사러 가기»로 바로 열려요.
4. **엔화 목록**(여행): 일본어 이름·세금·면세·판매처를 적고, «직원에게 보여 주기», **매장 모드**를 써요. 환율은 위쪽 «1엔 = □원».
5. 설정 > «목록과 예산»에서 목록을 더하고, 이름·통화·예산을 바꿔요. 산 돈이 예산의 80%를 넘으면 고양이가 비틀거리고, 넘기면 눈이 돌아가요.
6. 설정 > 백업에서 JSON으로 내보내 두면 폰을 바꿔도 옮길 수 있어요(사진 포함).

## 구글 시트 동기화(선택)
`apps-script/Code.gs`를 구글 시트의 앱스 스크립트에 붙여 넣고 웹 앱으로 배포한 뒤, 앱 설정에 웹 앱 주소와 비밀번호를 넣어요. 처음 «연결 확인»을 누를 때 넣은 비밀번호가 정해져요. 시트에서 직접 고쳐도 앱이 받아 가요. 스크립트를 고치면 «배포 관리 → 새 버전»으로 다시 배포해요(주소 유지).
